## 1. CRUD list page skeleton

```
PageHeader (title / description / actions: import outline, export outline, create variant="brand")
→ FilterBar (SearchInput / FilterSelect)
→ selection notice bar (AnimatePresence, optional)
→ DataTable (pagination / selectable / row actions)
→ FormDialog (create / edit)
→ ExportDialog / ImportDialog
```

```tsx
// Row is inferred from getItems' response (the API file types it from the OpenAPI doc)
const list = useCrudList(
  (params) =>
    getItems(params).catch((err: unknown) => {
      toast.apiError(err, '加载失败')
      return { items: [], total: 0 }
    }),
  { defaultPerPage: 20 },
)
const { data, total, loading, page, perPage, filters, fetchData, handlePageChange } = list

useEffect(() => {
  fetchData()
  // eslint-disable-next-line react-hooks/exhaustive-deps
}, [])

const runSearch = () => list.handleSearch({ search: search.trim(), status })
const reset = () => { setSearch(''); setStatus(''); list.handleReset() }
```

Pages generated by `pnpm scaffold` follow this skeleton. Field type → form component / table column:

| scaffold type | Form component | `FormValues` type | Table column | Default / value when editing |
|---|---|---|---|---|
| `str` / `str20` / `str50` / `str500` | `FormInput` | `string` | As is | `''` / `record.x ?? ''` |
| `text` | `FormTextarea` | `string` | `ellipsis: true` | `''` |
| `int` / `float` | `FormNumber` (`step={1}` / `step={0.01}`) | `number \| null` / `number \| string \| null` (decimals come back as strings) | `align: 'right'` + `tabular-nums` | `null` / `record.x ?? null` |
| `bool` | `FormSwitch` | `boolean` | `StatusBadge` (`是` / `否`, yes / no) | `false` / `Boolean(record.x)` |
| `date` | `FormDate` | `string` | `formatDate` | `''` / `formatDate(record.x, '')` |
| `datetime` | `FormDateTime` | `string` | `formatDateTime` | `''` / `record.x ?? ''` |
| `file` / `image` | `FormFileUpload` / `FormImageUpload` | `string \| null` | `查看` (View) link / thumbnail (`fileUrl(id)`) | `null` / `record.x ?? null` |
| `enum` / `dict` | `FormSelect` (`FIELD_OPTIONS.x` / `dicts[code]`) | the option values `\| null` / `string \| null` | option label / `dictLabel` | `null` (or the default) / `record.x ?? null` |

## 2. Create / edit form

```tsx
/** What the form holds and submits; checked against the create / edit body when passed to createItem / updateItem */
interface FormValues {
  name: string
  status: 'active' | 'inactive' | null
}
const EMPTY: FormValues = { name: '', status: 'active' }
const form = useForm<FormValues>({ defaultValues: EMPTY })
const [editing, setEditing] = useState<Row | null>(null)

const openCreate = () => { setEditing(null); form.reset(EMPTY); setOpen(true) }
const openEdit = (row: Row) => { setEditing(row); form.reset({ name: row.name ?? '', status: row.status }); setOpen(true) }  // only fill in the form's fields

const submit = async (values: FormValues) => {
  try {
    if (editing) await updateItem(editing.id, values)
    else await createItem(values)
    toast.success(editing ? '更新成功' : '创建成功')
    setOpen(false)
    fetchData()
  } catch (err) {
    toast.apiError(err, '操作失败')
    throw err                      // keeps FormDialog open
  }
}

<FormDialog open={open} onOpenChange={setOpen} title={editing ? '编辑' : '新增'} form={form} onSubmit={submit}>
  <FormInput control={form.control} name="name" label="名称" rules={{ required: '请输入名称', maxLength: { value: 100, message: '最多 100 个字符' } }} />
  <FormSelect control={form.control} name="status" label="状态" options={STATUS_OPTIONS} />
</FormDialog>
```

- Validation messages go in `rules` (required / minLength / maxLength / pattern / validate) and match the backend's messages
- Many fields: use `FormSheet`; two columns: `FormGrid`; custom controls (uploads, tree select): `FormCustom`
- Standalone form page (not a dialog): `<Form {...form}><form onSubmit={form.handleSubmit(save)}>...</form></Form>` (`@/components/ui/form`); see the profile page

## 3. Row actions and delete confirmation

```jsx
{
  key: 'actions', title: '', align: 'right', width: 132,
  render: (_, row) => (
    <div className="flex justify-end gap-0.5">
      <Button variant="ghost" size="sm" className="h-7 px-2" onClick={() => openEdit(row)}>编辑</Button>
      <ConfirmAction title={`删除「${row.name}」？`} description="删除后不可恢复。" confirmText="删除" onConfirm={() => remove(row)}>
        <Button variant="ghost" size="sm" className="text-danger hover:text-danger h-7 px-2">删除</Button>
      </ConfirmAction>
    </div>
  ),
}
```

In `remove`, do `catch → toast.apiError → throw`, so the confirmation stays open on failure. Button permissions reuse the page's existing `hasPermission` checks.

## 4. Import and export

```jsx
const normalizeFileType = (raw) => (['csv', 'xlsx'].includes(raw) ? raw : 'xlsx')

const handleExport = async ({ fields, fileType }) => {
  const type = normalizeFileType(fileType)
  const payload = { fields, file_type: type }
  if (selectedKeys.length) payload.ids = selectedKeys
  try {
    downloadBlobFile(await exportItems(payload), `xxx_export.${type}`)
    toast.success('导出成功')
    setExportOpen(false)
  } catch (err) {
    toast.apiError(err, '导出失败')
  }
}

<ExportDialog open={exportOpen} onOpenChange={setExportOpen} fieldOptions={EXPORT_FIELDS} ruleHint="…" onConfirm={handleExport} />
<ImportDialog
  open={importOpen} onOpenChange={setImportOpen} title="导入数据" targetLabel="客户"
  onDownloadTemplate={(t) => downloadTemplate(normalizeFileType(t)).then((b) => downloadBlobFile(b, `xxx_import_template.${normalizeFileType(t)}`))}
  onImport={(file) => importItems(file)}
  onImported={(res) => { toast.success(`导入成功：新增 ${res?.created || 0} 条`); fetchData() }}
  errorExportFileName="xxx_import_error_rows.csv"
/>
```

csv / xlsx only. Import failures (backend 400 + `error_rows`) are shown by ImportDialog, which lets the user download the error rows; the page doesn't need to handle them.

## 5. Status badges

```jsx
const STATUS = { active: { label: '启用', tone: 'success' }, disabled: { label: '停用', tone: 'neutral' } }
render: (v) => <StatusBadge tone={STATUS[v]?.tone ?? 'neutral'} dot>{STATUS[v]?.label ?? v}</StatusBadge>
```

tone: neutral (draft / disabled), brand (special roles), info (in progress), success (succeeded / enabled), warning (pending), danger (failed / abnormal).

## 8. Loading and empty states

- Tables: `DataTable loading` has built-in skeletons and an empty state (`emptyTitle` / `emptyDescription` / `emptyAction`)
- Other areas: `<Skeleton className="h-10 w-full" />` as a placeholder; `<EmptyState title="..." description="..." action={...} />`
- For the first load, initialize `loading` to `true` and call `setLoading(false)` in the promise callback; don't call `setLoading(true)` synchronously in `useEffect` (react-hooks/set-state-in-effect)

## 9. Feedback

- Success: `toast.success('已保存')`; failure: `toast.apiError(err, '保存失败')` (the backend's `{error}` message takes precedence)
- No `alert` / `window.confirm`; dangerous actions always use `ConfirmAction`
